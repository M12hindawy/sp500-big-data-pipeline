Pipeline Phases
End-to-end data flow from raw CSV to analytics
①
Data Source — Real S&P 500 Dataset
3.16 GB CSV file containing 20+ million real stock records from Kaggle. Covers 25 years (2000–2025) of daily OHLCV data for 500+ companies. No synthetic data — all records are real market data.
3.16 GB CSV 20M+ rows S&P 500 25 Years OHLCV Data
②
Producer — Historical Replay Streaming
Python producer reads the CSV and replays historical records as real-time events into Apache Kafka. Sends 5,000 records per run at 91+ records/second. Uses deterministic replay timestamps for watermark-correct streaming.
Python 3.8 kafka-python 91 rec/sec 5,000 msgs Replay Mode
③
Apache Kafka — Message Broker (KRaft Mode)
Apache Kafka 4.0 running in KRaft mode (no ZooKeeper). Topic: stock-market-data with 3 partitions, persistent volume for data durability across restarts.
Kafka 4.0 KRaft Mode 3 Partitions Persistent Volume Auto-restart
④
Apache Spark — Batch & Streaming Processing
Spark 3.5.6 runs two jobs simultaneously: batch pipeline processes the full 3.16 GB CSV into Silver (Parquet) and Gold (aggregated) layers. Streaming pipeline consumes Kafka in real-time with 5-minute windows and 10-minute watermarks.
Spark 3.5.6 Structured Streaming Batch ETL Parquet Output Window Aggregation
⑤
MinIO — Data Lake Storage (S3-compatible)
MinIO provides S3-compatible object storage for all pipeline layers. Bronze: raw CSV (3.16 GB). Silver: 25 Parquet files (cleaned, partitioned by year/month). Gold: 19 aggregated metric files. Checkpoints: 58 streaming state files.
MinIO S3 Bronze Layer Silver Layer Gold Layer boto3
⑥
PostgreSQL — Serving & Analytics Layer
PostgreSQL 16 stores 25,500 rows of aggregated daily market metrics computed by Spark. Airflow 2.10 orchestrates the daily pipeline DAG. pytest runs 20 quality gate tests covering schema, data quality, streaming semantics, and transformation correctness.
PostgreSQL 16 25,500 rows Airflow 2.10 pytest 20/20 Quality Gates
