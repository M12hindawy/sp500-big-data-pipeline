03 / PROCESSING

Data Validation & Quality Assurance Rules

Automated gatekeeping preventing corrupted data from entering trusted tiers.

Schema Integrity

Mandatory symbol, valid trading date, strict float64 price types, int64 volume. Missing required fields are instantly quarantined.

Value Realism Checks

Rejects prices ≤ 0, volume < 0. Validates that prices do not experience unnatural 100x decimal drift or format corruption.

OHLC Logical Rules

High must be ≥ Low, High must be ≥ Open and Close, Low must be ≤ Open and Close. Mathematical anomalies are logged and isolated.

03 / PROCESSING

Spark Structured Streaming & Replay Windows

Stateful stream aggregation with exactly-once idempotency.

Dual-Time Model

Synthetic Event Clock

Original historical trading_date preserved; synthetic clock advances 1.0s/record without wall-clock datetime.now() dependencies.

Replay Windows

4,335 Aggregation Windows

Computed via window(event_time, '5 minutes') with 10-minute watermark bounding state memory.

Fault Tolerance

58 MinIO Checkpoints

Persists committed offsets in MinIO S3. Stream restarts leave PostgreSQL table at exactly 4,335 rows with 0 duplicates.
